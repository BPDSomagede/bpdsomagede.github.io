REPOSITORY BPD DESA SOMAGEDE — SIAP UPLOAD

Isi paket ini sudah mencakup:
- Foto asli Kantor Kepala Desa Somagede sebagai header utama.
- Logo BPD Desa Somagede dan lambang Kabupaten Banyumas.
- Desain responsif yang mengacu pada mockup visual.
- Profil pengurus BPD lengkap beserta foto dan urutan jabatan.
- Halaman informasi, kegiatan, pembangunan, dokumen, galeri, aspirasi, dan kontak.
- SEO dasar, sitemap, robots.txt, PWA manifest, dan halaman 404.

CARA UPLOAD:
1. Ekstrak file ZIP.
2. Buka repository GitHub BPDSomagede.
3. Hapus isi lama agar tidak ada file ganda.
4. Klik Add file > Upload files.
5. Seret seluruh ISI folder DesaSomagede ke area upload, bukan folder ZIP-nya.
6. Klik Commit changes.
7. Tunggu GitHub Pages memperbarui situs.
