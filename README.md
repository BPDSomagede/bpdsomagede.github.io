# Portal BPD Desa Somagede — Final

Upload seluruh isi folder ini ke repository GitHub Pages.

## Penting sebelum publikasi
1. Buka `aspirasi.html` dan ganti nomor placeholder `628121234567` dengan nomor WhatsApp resmi BPD.
2. Ganti/tambah foto di folder `assets` sesuai dokumentasi resmi.
3. Untuk GitHub Pages, gunakan Settings → Pages → Deploy from branch → main → / (root).

Website ini sengaja dibuat static HTML/CSS/JS agar **langsung upload dan jalan**, tanpa Node, Astro, build, atau database.
